# My TUI Applications

## papers

TUI application that shows a menu of research papers to read. Once selected, a browser tab will be opened to show the paper pdf file. There's nice lofi background music too.

> Not a single line of code was written by LLM during the development of this TUI application (except the PAPER ASCII artwork header, which is an interesting program to develop)

### Quick Start

```sh
curl -fsSL "https://raw.githubusercontent.com/caongocthai/tui/refs/heads/main/papers/papers.sh" | bash
```
Use j/k to move down/up. Press enter to open the paper on a web browser to read.
